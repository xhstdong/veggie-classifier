# veggie-classifier
A frontend to interface with veggie classifier backend

Currently this repo consists of a frontend html file. It interfaces with a gradio-based huggingface spaces page where the fine-tuned vegetable classifier lives.

Frontend link: https://xhstdong.github.io/veggie-classifier/

Huggingface spaces link: https://huggingface.co/spaces/xhstdong/veggies

Alternative HF space with customized docker: https://huggingface.co/spaces/xhstdong/veggie-docker

**Note**: I am using the free tier of huggingface spaces, which winds down after some amount of inactivity. Spinning up again may take ~5mins
